## Fase 1 — Scaffold Proyek
1. `npm create astro@latest . -- --template minimal --install --no-git --yes` — scaffold Astro 5 non-interaktif (fallback: scaffold manual via `package.json` + `npm install astro` jika prompt interaktif mengganggu).
2. `npx astro add tailwind --yes` — Tailwind CSS v4 via plugin `@tailwindcss/vite`.
3. `npm install @fontsource-variable/inter @tailwindcss/typography` — font Inter self-hosted + plugin prose untuk body markdown proyek.

## Fase 2 — Design System (`src/styles/global.css`)
- Import Tailwind v4 + `@plugin "@tailwindcss/typography"`.
- `@custom-variant dark` berbasis **class** (bukan `prefers-color-scheme`) agar toggle bekerja.
- **Semantic color tokens** gaya Shadcn (background, foreground, card, border, muted, muted-foreground, primary, primary-foreground, secondary) — dua set nilai: `:root` (light) dan `.dark` (dark, default), dihubungkan ke Tailwind via `@theme inline` sehingga bisa dipakai sebagai `bg-background`, `text-muted-foreground`, dll. Palet: zinc untuk netral, emerald-400/500 (dark) & emerald-600 (light) untuk aksen.
- Font Inter sebagai `--font-sans`, smooth scroll, styling selection.
